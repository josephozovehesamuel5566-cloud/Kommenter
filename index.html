Introduction to JavaScript

JavaScript, often abbreviated as JS, is a high-level, dynamic, and interpreted programming language that has become one of the most essential technologies in modern web development. It was created in 1995 by Brendan Eich during his time at Netscape Communications, and astonishingly, it was developed in just about ten days to add interactivity to web pages, complementing HTML and CSS.

Welcome to DOM & DOM Manipulation

In this session, you are going to be learning how you can use JavaScript as a programming language to add interactivity and functionality to your web page.
